Overture — The Naming

A name that grew
with its purpose.

Every word in this paper hangs on three letters. So the paper begins where the pit began: with the name — because the name is the history.

🎻

The orchestra pit

In every theater there is a pit: the sunken place where the musicians sit — the ones who make the sound the whole room dances to, rarely in the spotlight, always holding the signal. The Open Source Orchestra tradition takes its name from this place. The pit is where the music actually comes from.

🏆

Play IT Together P.I.T. — Delhi, 2025

At ETHGlobal New Delhi 2025, Shaka built the OSO P.I.T.: a visual orchestra pit where musicians queue to perform — an orchestra activated by making its instruments permissionless, so anyone could Play IT together. ENS names as identity, a pure giving economy, zero fees. It won Most Creative Use of ENS. The pit got its first backronym — and its first arm.

📡

Public Information Transmission P.I.T. — Esmeralda, 2026

A year later, at Edge Esmeralda, the same three letters found their deeper signal. A transponder receives a transmission and retransmits it, faithfully, forever. A village's knowledge is exactly such a signal — and Public Information Transmission is the act of keeping it on the air. The Knowledge Transponder was born, and the pit became a protocol.

Both backronyms are canon. Play IT Together is the pit's heart — permissionless participation, everyone in the orchestra. Public Information Transmission is the pit's work — the signal carried forward as a public good. The name did not change; it deepened, the way a pit does when you keep digging and strike something luminous.

"The old name edgeTV belonged to existing streaming companies — the pit was always its true name. P.I.T. is the protocol; each archive is a P.I.T. — the pit of all kinds." — the declaration, 2026-07-25

Act II — The Protocol

Five stages down,
one signal up.

The protocol is deliberately reproducible by anyone: public sources, open tools, honest reporting. No step requires an API key you cannot get, a server you must rent, or a gatekeeper's blessing.

1

Crawl gather

Gather the gathering's knowledge from public sources — public Drive folders via embeddedfolderview, no API keys required. If you can see it in a browser, the protocol can reach it. Reproducible by anyone, anywhere.

2

Harvest transcribe

Transcribe every recording with open Whisper models. Match transcripts to media programmatically. Dedupe relentlessly. Raw footage becomes readable, searchable, quotable knowledge.

3

Audit radical honesty

Quality-probe every single file — 1-byte range requests, bitrate checks — and flag every casualty honestly in the UI. If a file is wounded, the archive says so. Radical honesty as design. Only verifiable claims.

4

Publish static & forever

Ship a static site — no backend, ~$0 infrastructure — with the Knowledge Transponder at its heart. An archive that costs nothing to run is an archive that never has to die.

5

Consent-First Governance the soul

Nothing enters the permanent public archive without explicit organizer and speaker consent. Compliance is enforced by recurring audits against public search indexes. This is not a feature of the protocol. This is the protocol's soul.

The thesisFork in one day

This paper was not written after the protocol shipped. It was written on the same day the protocol was declared — and that is the point. On 2026-07-25, in a single day: the P.I.T. universe was declared, its herald was born, the domains went live, the protocol site was published, the ancestor's code was reopened, and this white paper was written. One day.

⚑ The fork-in-one-day thesis

If we can fork it in a day, anyone can.

The protocol's test is not elegance — it is transmission speed. How fast can a community go from "we should have a pit" to a living archive? The Esmeralda genesis compresses the answer:

P.I.T. universe declared — day one
Herald born (PIT BOY 🕳️😤) — day one
Domains live (publicinform.com and kin) — day one
Protocol site published — day one
Ancestor tomb reopened (osopit restored) — day one
White paper written — this document — day one
"If anyone can have their agent fork it and deploy it in one freaking day like we just did — then everyone can have a pit." — Shaka, 2026-07-25

The one-day thesis is why the protocol's constraints are so strict: public sources only (anyone can crawl them), open models only (anyone can run them), static sites only (anyone can host them, forever, for nothing), and consent always (because speed without consent is extraction, and the pit is a gift).
